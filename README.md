# ARC Wallet UI Demo

A modern futuristic ARC Wallet UI concept built with React, Vite, TailwindCSS, and Framer Motion.

This is a frontend wallet interface demo inspired by modern Web3 wallet experiences with:
- Animated UI panels
- Wallet connection modal
- Send / Receive / Swap pages
- Assets dashboard
- Responsive futuristic design
- ARC branding and custom logo support

# Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/arc-wallet-demo.git
```

Go into project folder:

```bash
cd arc-wallet-demo
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open in browser:

```bash
http://localhost:5173
```

# Custom Logo

Place your ARC logo inside:

```bash
public/
```

Example:

```bash
public/Arc-Network-LOGO.png
```

Then update:

```tsx
const logo = '/Arc-Network-LOGO.png'
```
